# ROADMAP — 투자 아이디어 발견(Idea Discovery) 고도화

> **목적**: 매크로 투자자가 PPI 데이터에서 **의미 있는 투자 아이디어를 발견**하도록 돕는 신규 서비스·분석·UI의 우선순위 로드맵.
> 작성: 2026-06-11 · 기준: 코드 + Supabase 실DB 검증(시리즈 9,160개 · 관측 277만 행 · 최신 2026-04)
> 모든 항목은 CLAUDE.md 핵심 가치(Fast/Accurate/Inspiring)와 정확성 원칙(SA/NSA 혼합 금지·출처 표기·사전계산 우선·화면 로드 시 FRED 호출 금지)을 전제로 한다.

## Phase 1 — 즉시 (적재된 데이터만으로)

| 항목 | 난이도/임팩트 | 상태 |
|---|---|---|
| 1-1 파이프라인 패스스루 패널 | 하 / 상 | ✅ 구현 (2026-06) |
| 1-2 베이스효과 시뮬레이터 | 중하 / 상 | ✅ 구현 (2026-06) |
| 1-3 극단값 스크리너 | 중 / 상 | ✅ 구현 (2026-06) |

### 1-1. 파이프라인 패스스루 패널 ✅
- **가치**: 미가공(`WPSID62`) → 가공(`WPSID61`) → 최종수요(`PPIFIS`)로 물가가 전이되는 데 수개월. 상류 가속 + 하류 평온 = 헤드라인 상승 선행신호(금리·브레이크이븐·인플레 헤지 타이밍). 상류 급락 = 디스인플레 선행.
- **구현**: `lib/config/pipeline.ts`(SSoT) + `loadMetricsFor` 재사용 + `PipelineCard.tsx`. 전 단계 SA.

### 1-2. 베이스효과 시뮬레이터 ✅
- **가치**: "향후 N개월 MoM이 x%로 가면 YoY가 언제 몇 %인가" — 인플레 피크아웃/재가속 시점을 미리 보는 도구. 채권 듀레이션·커브 베팅의 핵심 질문에 직접 답한다.
- **구현**: `lib/analytics/`의 `projectYoyPath(values, assumedMoM, horizon)` 순수함수 + 단위 테스트 10개. 추세 차트 YoY 모드 "시나리오" 토글 + 프리셋(0% / +0.2% / 3M평균 / 직접 입력 ±5 클램프). `LineChart`에 `projected` 플래그 점선 프로젝션(실선·면적·방향색은 실측만). 전부 클라이언트 계산, "가정 기반 시뮬레이션 · 예측 아님" 캡션 상시. 후속 확장 여지: `/series` 상세 패널에 동일 토글.

### 1-3. 극단값 스크리너 (10년 백분위) ✅
- **가치**: 9,160개 중 "지금 역사적으로 비정상인 시리즈" 자동 발굴 — 마이크로 극단(특정 운임·식품·소재)이 섹터/종목 아이디어의 출발점. 현 Top Movers(절대값 상하위 5)는 고변동 시리즈만 반복 노출되는 한계 보완.
- **구현**: 마이그레이션 `series_trend_mv_add_pctile_z` — `yoy_pctile_10y`·`mom_pctile_10y`·`yoy_z10y`·`yoy_n_10y`(percent_rank 사전계산, 표본 n<24 NULL 가드). `/series`에 10Y 백분위 정렬 컬럼 + `#역사적극단` 태그(P95↑/P5↓, `isHistoricalExtreme` 순수함수) + Top Movers 6분할(백분위 상·하위 추가) + 상세 패널 `P · z` 병기. **z-score 단독 노출 금지 준수(상세 패널 병기 1곳만).**

### 1-4. ingest 자동화 + M5 배포 (기반)
- **가치**: 발표일에 수동 `npm run ingest:update`를 잊으면 모든 분석이 구식 데이터가 된다. "발표 즉시"라는 제품 전제의 자동화.
- **구현**: GitHub Actions(`.github/workflows/ingest.yml`) — 매일 08:30 ET 부근 실행, `release_schedule.next_date`가 오늘이면 `ingest:update`(가드: `--if-release-day` 플래그를 ingest에 추가), 주 1회 `ingest:incremental`. 시크릿 4종은 Actions secrets. Vercel 배포 + 환경변수, ingest 종료 시 `revalidatePath` 웹훅(선택). Vercel cron은 함수 실행시간 제한·CLI 스크립트 환경 불일치로 비권장.

### 1-5. P1 잔여 3종 (PRD §6.2)
- **즐겨찾기(P1-2)**: localStorage 최대 5개, `/series` 핀 토글 + 목록 상단 고정, 신규 훅 `useFavorites()`.
- **요약 패널(P1-3)**: `SeriesDetailPanel`에 선택 기간 최고/최저·추세 방향·최근 변화 — `summarizeRange()` 순수함수 + 테스트, 클라이언트 계산.
- **오버레이(P1-5)**: `LineChart` 다중 시리즈 + **동일 SA/NSA·동일 모드만 허용 가드**(위반 시 비활성+사유 툴팁). 지수 레벨 오버레이 금지(기준연도 상이), 변화율만.

## Phase 2 — 발굴 엔진 (신규 분석·일부 재적재)

### 2-1. 발견 공백 보수 (2-2의 전제)
`lib/fred/client.ts` 카테고리 조회에 offset 페이지네이션 추가, `scripts/ingest.ts` 발견 실패 카테고리를 `failed-categories.json`으로 기록·재시도. 이후 `ingest:incremental` 1회로 NAICS 32/33(금속·자동차·화학·제약·반도체) 회수. NAICS 2자리 분포 검증 쿼리를 README에 기록.

### 2-2. 산업 마진 프록시
- **가치**: 산출가(산업 PCU) − 투입가(원자재 WPU/WPSID) 스프레드 확대 산업 = 마진 확장 → 주식 섹터 비중확대 아이디어. 기존 MarginSpreadCard(경제 전체)의 섹터 버전.
- **페어 예시**(적재 확인분): 식품가공 `PCU311311`↔`WPU01`, 트럭운송 `PCU484121484121`↔연료 `WPU0561`, 건설 `PCU236400236400`↔자재 `WPSID612`. 금속·자동차는 2-1 후.
- **정확성 규칙**: 페어는 같은 계열(NSA-NSA)끼리, **비교 지표는 YoY만**(NSA의 ann3m 비교 금지). 캡션 "투입 바스켓 근사 — 단일 원자재 프록시" 명시. `lib/config/margin-proxies.ts` + `calcMarginGap` 재사용.

### 2-3. 상품군 diffusion 히트맵
- **가치**: 인플레가 "넓게" 퍼지는지(끈적함) vs 소수 품목 주도인지의 **역사적 추이** — 현 breadth는 최신 한 시점뿐.
- **구현**: `lib/config/commodity-groups.ts` — WPU 2자리 프리픽스 → BLS 상품군 15개 결정적 매핑(타이틀 추론 대체). 신규 MV `group_breadth_mv`(상품군×월, 최근 120개월, MoM>0 비중). UI는 기존 `Heatmap` 재사용(행=상품군, 열=월, 셀=상승 비중%). NSA 균질 집계 + "방향 비중만 집계(NSA)" 캡션.

### 2-4. 역사적 유사국면(analog) 탐색
- **가치**: "지금 같은 모멘텀 조합이던 과거 시점 → 이후 12개월 YoY 경로" — 시나리오 무게중심 직관 도구.
- **구현**: `findAnalogs(history, currentVector, k)` 순수함수 + 테스트 — 벡터 [yoy, Δyoy(3m), Δyoy(12m)] 표준화 후 유클리드 거리, 직전 24개월 제외. 표본은 `PPIACO` YoY(1913~, 1,300개월+). 상위 3개 시점 + 이후 12개월 경로 소형 멀티라인. **"과거 사례 나열이며 예측 아님" 캡션 필수.** 확률 제시 금지.

### 2-5. AI 고도화
- 월간 브리핑: `dashboard_insight.body_long`(3~5문장) — 입력에 파이프라인 단계·diffusion 추이·극단값 상위 3개 추가. 적재 시점 1회 생성 원칙 유지.
- "이번 달 주목 시리즈": **선정은 결정적**(백분위 극단 + `추세반전` 태그 교집합 상위 N), **LLM은 서술만**. 수치 생성·선정을 LLM에 위임하지 않는다.

## Phase 3 — 조건부 (선행 조건 충족 후)

### 3-1. 리드-래그 패널 (범위 엄격 제한)
경제 논리가 선행하는 **고정 페어 3~4개만**(WPSID62→WPSID61, WPSID61→PPIFIS, PPIFIS→CPIAUCSL). YoY ±12개월 교차상관 막대 + "역사적 최적 리드 N개월", 최근 20년 윈도우. `crossCorrelation()` 순수함수 + 테스트, 사전계산. **금지**: 전수 자동 상관 스캔·그레인저 인과·p-value — 다중비교 가짜 신호 양산.

### 3-2. 시장 반응 연계 — 보류
컨센서스 이력 1개월(F5)로 이벤트 스터디 표본 0. **경로**: ① M6 컨센서스 입력 UI(또는 매월 시드 갱신 루틴)로 이력 축적 → ② 12개월+ 쌓인 뒤 일간 시리즈(`T5YIE`·`T10YIE`·`DGS10`) 적재와 발표일 ±1일 변화 표 검토(월간 전제와의 frequency 충돌 설계 필요). 회귀·유의성 통계는 하지 않고 사례 표만. 참고: FRED `SP500`은 라이선스상 최근 10년만 제공.

### 3-3. 발표 알림 — 보류
PRD §2.2 비목표("실시간 알림")와 충돌 — PRD 갱신 협의 전 보류. D-day 배지 + 1-4 자동화로 실효 가치 대부분 충족.

## 하지 말아야 할 것

1. **`PPIITM`·`PPICRM` 사용** — 2015-12 단종. WPSID 체계로 대체.
2. **SA/NSA 혼합 비교** — 파이프라인은 WPSID(SA) 통일, 산업 마진 페어는 NSA-NSA YoY만.
3. **전수 상관/그레인저/유의성 검정** — 9천 개 다중비교는 스퓨리어스 양산. 고정 페어 교차상관까지만.
4. **PCE 정밀 nowcast** — 가중치 비공개. 방향 신호만(기존 원칙).
5. **z-score 단독 극단 판정** — 물가 변화율은 두꺼운 꼬리. 백분위 주지표.
6. **LLM에 수치 계산·시리즈 선정 위임** — 선정·수치는 결정적 계산, LLM은 서술만.
7. **화면 로드 시 FRED 호출** — 신규 기능도 예외 없음(시뮬레이터·analog 모두 DB/클라이언트 계산).
8. **서프라이즈 이벤트 스터디 즉시 구현** — 컨센서스 이력 부재로 불가능.
9. **시뮬레이션·유사국면을 예측처럼 표기** — "가정 기반/과거 사례" 캡션 의무.
